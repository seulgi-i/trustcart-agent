# Grok 답변 (2026-11-04)

## 첫 번째 결정 질문에 대한 답
예, 그 방향으로 가자. 단 두 가지는 축소해서 핵심 흐름에 포함해줘.
1. 의도와 장바구니 일치 검증: AP2 서명이나 프로토콜 준수는 빼되, 사용자 요청을 구조화한 Intent(예산, 카테고리, 수량)를 저장하고 장바구니와 서버 코드로 비교해서 불일치면 차단하거나 승인으로 보내는 것까지는 넣어줘. 이게 데모의 차별점이야. README에는 "AP2의 Intent/Cart Mandate 개념에서 영감"이라고만 적어줘.
2. 결제 전 확인 화면: 자동 지연 결제 대신, 최종 확인 화면에 에이전트가 고른 근거, 걸린 정책 규칙, 인젝션 탐지 결과를 보여주고 사용자가 승인해야 PayPal capture가 되게 해줘.
- 감사 로그는 해시 체인 없이 단순 append-only 이벤트 로그로 시작하고, 시간이 남으면 해시 체인을 확장 기능으로 추가.
- PayPal 계정 가입이 지연 중이므로 MockProvider로 먼저 개발.
